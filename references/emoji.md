# Emoji 参考

`icon` 字段（`insight` / `list-block.items[]` / `flashcards[]`）只能使用下表里的 emoji。`code` 和正文文本不受限。

| emoji | 用在哪 |
|---|---|
| 💡 | 洞察、关键发现（`insight` 块首选） |
| 🧠 | 核心概念、学习要点 |
| 🎯 | 学习目标、重点 |
| 💎 | 最佳实践、宝贵经验 |
| 🔨 | 动手实践、步骤操作 |
| 🧩 | 组成部分、模块 |
| 🔗 | 概念关系、数据流 |
| 🔄 | 重复流程、迭代 |
| 📋 | 检查项、规范列表 |
| 📝 | 正文要点、备注 |
| 📖 | 参考资料、延伸阅读 |
| 💬 | AI 对话、讨论 |
| ❓ | 测验、思考题 |
| ✅ | 正确示例、推荐做法 |
| ❌ | 错误示例、避免做法 |
| ⚠️ | 注意事项、常见陷阱 |
| 🎨 | 视觉、配色、排版 |
| 💻 | 代码示例、技术内容 |
| 🔍 | 深入分析、代码审查 |
| 🌐 | 外部服务、全局视图 |
